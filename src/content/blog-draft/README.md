Blog draft workspace
====================

Use this directory for unpublished blog content.

Rules
-----

- Keep the same structure used in `src/content/blog`.
- One post per folder (`<slug>/`), with language files like `es.md` or `en.md`.
- Keep post images inside the same post folder.

Publishing
----------

When a post is ready, move its folder from `src/content/blog-draft` to `src/content/blog`.
